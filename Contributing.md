## Code of Conduct
By contributing, you agree to uphold our [Code of Conduct](CODE_OF_CONDUCT.md). We expect all participants to be respectful, inclusive, and professional. Harassment, discrimination, or unethical behavior (e.g., promoting unauthorized attacks) will not be tolerated.

## How to Contribute
1. Fork the repository.
2. Create a new branch: `git checkout -b feature/your-feature`.
3. Make your changes.
4. Commit with a descriptive message: `git commit -m "docs: update lab setup guide"`.
5. Push to your branch: `git push origin feature/your-feature`.
6. Open a pull request (PR) using the provided template.

> ⚠️ Do not submit PRs without an associated issue unless it's a minor fix (e.g., typo).

## Reporting Bugs
Before submitting:
- Ensure you're using the latest version of **VirtualBox** and lab images.
- Search existing [issues](https://github.com/your-repo/issues) to avoid duplicates.

When reporting:
- Include OS, VirtualBox version, and error logs.
- Provide step-by-step reproduction instructions.
- Use the **Bug Report** template.

## Suggesting Enhancements
- Propose features that benefit most users (e.g., new lab scenarios).
- Justify your suggestion with use cases or references.
- Use the **Enhancement Proposal** template.
- Avoid requests for niche or overly complex setups.

## Lab Setup Rules
- All VMs must use **Host-Only Networking** by default for isolation.
- Pre-configured VMs (e.g., Kali, Metasploitable) must include SHA256 checksums.
- No real credentials or sensitive data allowed in configurations.
- Document all setup steps clearly for reproducibility.

## Commit Guidelines
- Write clear, concise commit messages using [Conventional Commits](https://www.conventionalcommits.org):
  - `feat: add OWASP WebGoat lab setup`
  - `fix: correct network config in Kali VM`
  - `docs: improve README instructions`
- Keep changes focused: one feature or fix per PR.
- Test your changes before submitting.

By contributing, you confirm that:
- You authored 100% of the content.
- You have the right to license it under the project’s **MIT License**.
- Your contributions are not generated by AI tools unless explicitly permitted.
